# Соломон

Личный ИИ-секретарь в Telegram: принимает поручения голосом, текстом и
фотографией, понимает их обычным языком, сохраняет и напоминает в срок —
чтобы человек не держал свои дела в голове.

Документы: `idea.md` (зачем) → `spec.md` (что) → `techspec.md` (как) →
`design.md` (как выглядит). Правила работы — `CLAUDE.md`. Очередь работ —
`specs/README.md`. Визуал большого изменения одобряется прототипом до
кода — `prototype/README.md`.

## Как запустить

Нужны [uv](https://docs.astral.sh/uv/) и Node 24. Перед первым запуском
скопируйте `.env.example` в `.env` и заполните значения — без них процесс
не стартует и скажет, какой переменной не хватает. Кроме токена бота и
ключей Supabase там два значения для разбора поручений: `ANTHROPIC_API_KEY`
(ключ Claude, тратит деньги) и `OWNER_TIMEZONE` — часовой пояс владельца
в виде `Asia/Yekaterinburg`, без него «в пятницу» не превратить в дату.

```bash
uv run --directory bot solomon-bot     # бот: long polling, Ctrl+C останавливает
npm --prefix miniapp run dev           # Mini App: адрес печатает Vite
```

Напоминания приходят, пока бот запущен: цикл отправки живёт в том же
процессе, что и опрос Telegram. Компьютер был выключен — созревшее не
пропадает, оно лежит в базе и уходит первым тиком после запуска.

Схема базы — миграции в `supabase/migrations/`: применяются
`supabase db push` из корня репозитория или тем же SQL в редакторе панели
Supabase. Первое подключение проекта — по чек-листу `supabase/README.md`.

Жива ли база — `uv run --directory bot solomon-health`.
Проверки перед коммитом — `node scripts/gate.mjs` (см. `CLAUDE.md`
§«Сдача изменения»).

Как помощник понимает поручения — `uv run --directory bot pytest -m live`:
десять русских примеров уходят в Claude по-настоящему и сверяются с
ожидаемым разбором. Нужен ключ, стоит денег, в воротах не участвует.
