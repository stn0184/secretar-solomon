# Прототип 005 — список задач и карточка в Mini App

Режим: **канвас**. Четыре артборда, слева направо — путь человека:
список → тот же список без задач → карточка задачи → подтверждение удаления.

Отправная точка — `prototype/000-first-screens/` (экраны 04–06 и
`tokens.css`): экраны бота (01–03) и памяти (07–08) в этап 005 не входят.

## Как смотреть

Откройте в браузере файл `canvas.html` — всё полотно на одной странице,
с переключателем темы (как в системе / светлая / тёмная).

Отдельный экран можно открыть его файлом `NN-*.dc.html`.

После правки артбордов полотно пересобирается:

    node prototype/005-first-screens/build-canvas.mjs

## Экраны

| Файл | Что на нём |
|---|---|
| `01-tasks.dc.html` | Список активных задач по группам срока: просрочено, сегодня, на неделе, позже, без срока; идеи и желания — внизу |
| `02-tasks-empty.dc.html` | Задач нет: объяснение, две фразы-подсказки, кнопка «Вернуться в чат» |
| `03-task-card.dc.html` | Карточка: поля, исходное сообщение целиком, напоминания, кнопки «Сделано» и «Удалить» |
| `04-task-card-delete.dc.html` | Та же карточка с системным окном Telegram «Удалить задачу?» |

`tokens.css` — предложенный визуальный язык (цвет, шрифт, плотность,
тёмная тема). На одобрении он переезжает в `design.md` §1; соответствие
теме Telegram — ниже.

## Токены → тема Telegram

| Токен прототипа | `--tg-theme-*` |
|---|---|
| `--app-bg` | `secondary-bg-color` |
| `--surface` | `bg-color` (в тёмной — `section-bg-color`) |
| `--line` | `section-separator-color` |
| `--ink` | `text-color` |
| `--ink-2` | `subtitle-text-color` |
| `--ink-3` | `hint-color` |
| `--accent` / `--accent-ink` | `button-color` / `button-text-color` |
| `--urgent` | `destructive-text-color` |
| `--important`, `--ok`, `--guess` | своих в теме нет — фиксированные пары под светлую и тёмную |

## Важно

Прототип **не работает**: кнопки не нажимаются, форм нет, данных из базы нет.
Все имена и даты **выдуманы**; «сегодня» на экранах — среда, 30 сентября.

**Статус:** одобрен 27.09.2026

**Что одобрено:** два экрана (список и карточка) без нижних вкладок;
порядок групп списка — Просрочено / Сегодня / На неделе / Позже / Без
срока / Идеи и желания, пустые группы скрыты; приоритет в списке только
«Высокий» — полоской и меткой; метки «Я обещал» / «Обещали мне» /
«Перепроверьте»; плотность и капитель заголовков групп — как нарисовано;
пустое состояние с кнопкой «Вернуться в чат»; карточка со строками
полей, исходным сообщением целиком, напоминаниями и двумя кнопками;
подтверждение удаления — системным окном Telegram, не своим; два «назад»
(стрелка Telegram и своя «‹ Задачи») — оба. Экраны памяти и бота из
прототипа 000 в этап не входят.
