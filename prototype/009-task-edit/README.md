# Прототип 009 — правка задачи из приложения

Режим: **витрина**. Экраны собраны из настоящих компонентов Mini App
(`Header`, `Field`, метки, `SourceMessage`, `Reminders`, `Actions`) на
моковых данных; новое — строка «Изменить» в карточке, вопрос бота рядом
с «Перепроверьте» и форма правки. Предмет — `specs/009-task-edit/spec.md`,
`techspec/11-edit.md`.

## Как смотреть

    cd miniapp
    npm run dev -- --host 127.0.0.1

Затем в браузере откройте:

- http://127.0.0.1:5173/prototype/009 — светлая тема;
- http://127.0.0.1:5173/prototype/009?scheme=dark — ночная тема Telegram.

Адрес — цифрами: без `--host` Vite слушает только IPv6-`localhost`, и на
машине владельца браузер страницу не открыл.

Если порт 5173 занят, Vite выберет другой и напишет его в консоли.
С телефона в той же Wi-Fi-сети: `npm run dev -- --host`, адрес — строка
`Network` в консоли, путь тот же `/prototype/009`.

Страница есть **только в режиме разработки**: маршрут стоит в
`miniapp/src/main.tsx` под `import.meta.env.DEV`, в сборку (`npm run build`)
файлы прототипа не попадают — проверено.

## Что решено на прототипе

- **Вход в форму** — строкой «Изменить» внизу карточки полей, а не
  третьей кнопкой рядом с «Сделано» / «Удалить»: правка относится к полям,
  а три кнопки в ряд на телефоне шириной 360px не помещаются.
- **Форма заменяет карточку** на том же экране (роутера нет, §2.3);
  напоминания в форме не показываются — их пересчитает база, старые
  вводили бы в заблуждение. Исходное сообщение остаётся внизу: по нему
  видно, что именно бот понял не так.
- **Поля** — стопкой: подпись 13/17 над полем, строки разделены линией,
  как в карточке. Ввод — 16px (меньше iOS увеличивает страницу).
- **Выбор из вариантов** — ряд из трёх кнопок на обычных `radio`;
  выбранная — цветом действия (`--accent-weak` / `--accent`). Высокая
  срочность в форме жёлтым не красится: цвет — у метки в карточке.
- **«Без срока»** — флажок под днём и часом; час заперт, пока нет дня.
- **Вопрос бота** — в карточке мелким текстом под «Перепроверьте», в форме
  — блоком с фиолетовой кромкой (`--guess-weak`), тот же смысл «сомнение
  помощника». Новых токенов нет.
- **Кнопки формы** — «Сохранить» (главная, слева, как «Сделано») и
  «Отмена»; «назад» Telegram и своя «‹ Задача» делают то же, что «Отмена».

## Не нарисовано намеренно

Загрузка, ошибка, «мало/много данных» — текстом в `design.md` §2 на
реализации. Подсказка «срок уже прошёл», «Напишите, что сделать.»,
отказ базы и «Задача не найдена…» — состояния формы из приёмки спеки,
их тексты заданы там. Окно «Бросить правку?» — системное окно Telegram,
как подтверждение удаления в 005. Строка бота «Перенёс: …» — в чате,
не в приложении.
