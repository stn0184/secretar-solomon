# Прототип 000 — первые экраны «Соломона»

Режим: **канвас**. Восемь артбордов, слева направо — путь человека:
поручение → непонятое поручение → напоминание → Mini App (списки, карточка, память).

## Как смотреть

Откройте в браузере файл `canvas.html` — всё полотно на одной странице,
с переключателем темы (как в системе / светлая / тёмная).

Отдельный экран можно открыть его файлом `NN-*.dc.html`.

После правки артбордов полотно пересобирается:

    node build-canvas.mjs

## Экраны

| Файл | Что на нём |
|---|---|
| `01-bot-capture.dc.html` | Бот: приём поручения (текст и голосовое) и подтверждение своими словами |
| `02-bot-unclear.dc.html` | Бот: не понял — исходное сообщение целиком и один вопрос |
| `03-bot-reminder.dc.html` | Бот: напоминание в срок и отметка о выполнении (кнопкой и словом) |
| `04-app-tasks.dc.html` | Mini App: активные задачи, штатное состояние |
| `05-app-tasks-empty.dc.html` | Mini App: задач нет |
| `06-app-task-card.dc.html` | Mini App: карточка задачи с источником |
| `07-app-memory.dc.html` | Mini App: память — факты и предположения |
| `08-app-memory-empty.dc.html` | Mini App: память пуста |

`tokens.css` — предложенный визуальный язык (цвет, шрифт, плотность, тёмная тема).
На одобрении он переезжает в `design.md` §1.
