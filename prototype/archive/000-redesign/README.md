# Прототип 000 — редизайн Mini App: одна разметка, две темы

Режим: **канвас**. Прототип не из очереди этапов (номер `000`): тема —
редизайн Mini App. Владелец просил «очень крутой дизайн», календарь
(«может быть Гант»), анимации («цифры крутились, фон плавал»). Новые
понятия на экранах — сферы (`techspec/30-spheres.md`) и часы по сферам
(`techspec/31-hours.md`).

## Круги

- **Круг 1** (10.10.2026): три направления с разной разметкой — «Ночное
  стекло», «Тихая роскошь», «Банк-люкс».
- **Решение владельца после круга 1:** «Ночное стекло» снято. Остаются
  «Банк-люкс» и «Тихая роскошь» — как **две темы одной разметки**: тема
  меняет только вид (цвета, шрифты, поверхности, характер движения), а
  не устройство экранов. По умолчанию тема следует за Telegram, вручную
  переключается в настройках.
- **Круг 2** (этот): общая разметка, собранная из лучшего от обоих
  направлений, и каждый экран в обеих темах.

Главный вопрос круга 1 решён одобрением: приложение перестаёт брать
цвета и шрифт из темы Telegram (`design.md` §1, прежнее правило оставлено
там датированной заметкой). От Telegram остаётся только выбор
светлая/тёмная, по нему выбирается тема. Второй UI-kit не заводится:
компоненты свои, меняются токены и разметка.

## Как смотреть

Откройте в браузере `canvas.html` — всё полотно на одной странице. Два
ряда: «Банк-люкс» (тёмная) и «Тихая роскошь» (светлая), слева направо —
путь по экранам. Сверху переключатель «Движение» (как в системе /
включено / выключено = reduced motion) и кнопка «↻ Повторить анимацию».
Шрифты грузятся из Google Fonts, без сети экраны покажутся системным
шрифтом.

Отдельный экран — файл `bank-NN-*.dc.html` или `quiet-NN-*.dc.html`.
Артборды генерируются; после правки:

    node prototype/000-redesign/make-boards.mjs
    node prototype/000-redesign/build-canvas.mjs

## Экраны

Набор одинаковый в обеих темах.

| Файл | Что на нём |
|---|---|
| `*-01-today` | «Сегодня»: итог дня крупной цифрой, доли сфер полосой с подписями, дела без часа, нить дня с капсулами (высота по длительности, «Свободно 40 мин», линия «сейчас») |
| `*-02-week` | «Неделя»: итог крупной цифрой, день — одна строка блоками сфер, справа часы дня цифрами; ниже сферы полосами «встречи · переписка» |
| `*-03-spheres` | «Сферы»: все четыре видны разом — часы за неделю, полоса для сравнения, открытые дела, первая запись «что Соломон знает»; «Без сферы и о себе» |
| `*-04-tasks` | «Дела»: «По сроку / По сферам», группы по сроку, строка — отметка сферы, суть, сфера и срок со значком, метки, «›» |
| `*-05-card` | Карточка дела: время крупно, поля стопкой, «Перепроверьте», напоминания, исходное голосовое, «Сделано / Изменить / Удалить» |
| `*-06-settings` | «Оформление»: «Как в Telegram» (по умолчанию) · «Тихая роскошь» · «Банк-люкс»; вход — меню ⋯ Telegram → «Настройки» |
| `*-07-today-empty` | «Сегодня» без встреч и дел: без цифры и полосы — объяснение, примеры, кнопка в чат |
| `*-08-week-empty` | «Неделя» без часов: без пустой сетки — объяснение и примеры |
| `*-09-spheres-empty` | «Сферы», когда сфер нет: пунктирное место под первую сферу, как их назвать |
| `*-10-tasks-empty` | «Дела», когда дел нет: текст из `design.md` §2 со словом «дела» |

## Общая разметка — что откуда взято

- **Сегодня:** крупная прокручивающаяся цифра часов — из Банк-люкса; нить
  дня с капсулами и «Свободно …» — из Тихой роскоши; доли сфер — полосой
  с подписями (плитки 2×2 из Банк-люкса съедали место у ленты).
- **Неделя:** одна строка на день — из Тихой роскоши; часы дня цифрами
  справа — из Банк-люкса.
- **Сферы:** список, все сферы разом — из Тихой роскоши; кошелёк «по одной»
  снят. В тёмной теме карточка выглядит как карта из камня сферы
  (с чипом и бликом), в светлой — белая карточка с цветной полосой.
  Структура одна. Чтобы четыре сферы поместились разом, у сферы видна
  одна запись «что Соломон знает», остальные — «ещё 2».
- **Дела и карточка дела:** одна структура. Строка — отметка сферы
  (в тёмной — монограмма-«логотип», в светлой — тонкая полоска), суть,
  «сфера · срок», метки вторым рядом, «›». Карточка — время крупно
  (Банк-люкс), поля стопкой и исходное сообщение цитатой (Тихая
  роскошь).

### Что из «лишнего» осталось

- **Переключатель «По сроку / По сферам» — остаётся.** Сферы — главное
  новое понятие редизайна, и «что у меня по РЕЙВА» — естественный вопрос
  к списку. Переключатель только перегруппировывает тот же список:
  данных и действий не добавляет, ошибиться им нельзя.
- **Кружок «Сделано» в строке — снят.** Это новое действие из списка в
  одно касание рядом с «›»: легко промахнуться, а у повторяющегося дела
  «Сделано» переносит его на следующий раз, и это объясняет карточка
  (`design.md` §3, повтор). «Сделано» остаётся в карточке, как сейчас.
  В нити «Сегодня» ✓ — только отметка состояния у сделанного, у открытых
  кружка нет.

## Две темы

| | Банк-люкс (тёмная) | Тихая роскошь (светлая) |
|---|---|---|
| Включается | тёмная тема Telegram или вручную | светлая тема Telegram или вручную |
| Фон | чёрный `#050505`, карточки `#101010` с тонкой линией | тёплая бумага `#F6F3EE`, белые карточки с мягкой тенью |
| Акцент | золото `#D9B76E`: действие, единицы цифр, «сейчас» | глубокая олива `#2F4A3D`: действие; «сейчас» — красным |
| Сферы | камни: сапфир, изумруд, гранат, аметист | приглушённые: индиго, терракота, охра, шалфей |
| Шрифт | Inter Tight; крупные цифры тонкие (200) | заголовки и цифры — Lora, текст — Inter |
| Кнопки | пилюли, главная — золотой градиент | скругление 14, главная — олива |
| Движение | тёплый свет за цифрой 30–36 с, блик по картам-сферам | два тёплых пятна еле дышат 40–46 с, блика нет |

Общее движение: цифры прокручиваются по разрядам, как у NumberFlow
(320 мс, шаг 40 мс; на реализации — от прежнего значения к новому);
полосы вырастают за 380 мс, лесенкой. Фон двигает только пятна
(`transform`) с готовым мягким градиентом, без `blur`: это дёшево для
слабых телефонов. `prefers-reduced-motion: reduce` — всё стоит в
конечном виде. Стекла (`backdrop-filter`) в обеих темах нет.

Контраст текста к фону проверен: от 4,9:1 (вторичный текст на бумаге)
до 10:1. Белый текст на картах-камнях — не ниже 5,2:1 и под бликом
(изумруд для этого затемнён). Ниже 4,5:1 нет.

## Что решено на прототипе (за владельца, легко отвергнуть)

- **Тема по умолчанию** — «Как в Telegram»: тёмная → Банк-люкс, светлая →
  Тихая роскошь, меняется сама вместе с Telegram. Вручную — меню ⋯ →
  «Настройки» → «Оформление» (кнопка настроек Mini App в Telegram).
- **Четыре вкладки** «Сегодня · Неделя · Сферы · Дела». «О себе» отдельной
  вкладкой не стало: это последняя карточка «Без сферы и о себе» на
  «Сферах».
- **Цвет сферы** назначается по порядку заведения из палитры темы,
  владелец его не выбирает. Названия сфер показаны с заглавной.
- **Сфера без минут в итоге не называется** — как в ответе бота (§31.2).
- **Значки из чата** (`techspec/29-icons.md`) стали языком меток: 📅 — с
  часом, 🔔 — без часа, 💬 — переписка, 💡 — идея.
- **Смысловые цвета меток** те же, что сейчас (жёлтый — приоритет,
  фиолетовый — «Перепроверьте», синий — обещание), тон подобран под тему.

## Важно

Прототип **не работает**: кнопки не нажимаются, данных из базы нет.
Все имена, дела, часы и даты **выдуманы**. «Сегодня» на экранах —
четверг, 8 октября, сейчас 16:40.

**Статус:** одобрен 10.10.2026

**Что одобрено (круг 2):**

- **Одна разметка на обе темы.** Экраны устроены одинаково; тема меняет
  только цвета, шрифты, поверхности и характер движения.
- **Вкладки** «Сегодня · Неделя · Сферы · Дела».
- **Порядок экранов и плотность** — как на полотне: Сегодня → Неделя →
  Сферы → Дела → Карточка дела, «Оформление» из настроек, пустые
  состояния 07–10. На «Сегодня» до прокрутки видно около четырёх событий
  нити — **принято как есть**.
- **Выбор темы:** по умолчанию «Как в Telegram» (тёмная → Банк-люкс,
  светлая → Тихая роскошь); вручную — меню ⋯ Telegram → «Настройки» →
  «Оформление».
- **«По сроку / По сферам»** в «Делах» остаётся.
- **«Сделано» — только в карточке дела**; кружка в строке списка нет, в
  нити «Сегодня» ✓ — только отметка состояния.
- **«О себе»** переехала в карточку «Без сферы и о себе» на «Сферах»,
  отдельной вкладки нет.
- **Движение:** прокрутка цифр 320 мс (шаг 40 мс, от прежнего значения к
  новому), полосы 380 мс лесенкой, фон — только `transform` пятен,
  `backdrop-filter` не используется, при reduced motion всё сразу в
  конечном виде.
- **Шрифты** (Inter Tight; Lora + Inter) кладутся в сборку Mini App, из
  Google Fonts не грузятся — Google только на прототипе.
- **Снято:** «Ночное стекло» — после круга 1; кошелёк «по одной сфере»
  и выписка вместо нити — при слиянии в общую разметку.

Решения перенесены в `design.md`: §1 — токены обеих тем и правило выбора,
§2 — пустые состояния, §3 — компоненты, которые добавит реализация,
§4 — строка учёта.
