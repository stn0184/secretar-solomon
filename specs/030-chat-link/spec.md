## Проблема

Соломон пишет «Из переписки с Игорем (Telegram) записал: …» и «Вы не
ответили Игорю — он спрашивал, …», но чтобы ответить или уточнить,
владельцу приходится искать этот чат руками. Владелец (2026-10-08): нужна
ссылка на чат с этим человеком.

## Решение

Под обоими сообщениями — кнопка-ссылка «Открыть чат», рядом с «Убрать».
Ссылка строится по площадке:

- **Telegram:** есть @username — `https://t.me/<username>`; нет —
  `tg://user?id=<id>`. Telegram может отвергнуть кнопку с id из-за
  настроек приватности собеседника — тогда сообщение уходит без неё (в
  журнал — только факт), а не теряется.
- **Instagram:** ссылка на Direct по `username` собеседника (формат —
  по актуальной документации Meta, не по памяти).
- **MAX:** кнопки нет — у пересланного и групп нет надёжной ссылки.

`username` собеседника хранится в состоянии чата (`chat_threads`, новая
колонка) и обновляется с каждым сообщением: имя пользователя в Telegram
можно сменить. Кнопка остаётся и после «Убрать» (сообщение
пересобирается вместе с ней).

## Чего не делаем

- Не открываем чат на конкретном сообщении — только чат с человеком.
- Не делаем ссылок для MAX и групп.
- Не меняем текст сообщений и приложение.
- Не храним телефон собеседника.

## Приёмка

1. КОГДА бот присылает «Из переписки с … (Telegram) записал» или «Вы не
   ответили …» о собеседнике с @username, под сообщением ДОЛЖНА быть
   кнопка «Открыть чат», ведущая на `https://t.me/<username>`.
2. КОГДА у собеседника нет @username, кнопка ДОЛЖНА вести на
   `tg://user?id=<id>`; КОГДА Telegram отверг такую кнопку, сообщение
   ДОЛЖНО всё равно прийти — без неё.
3. КОГДА владелец нажал «Убрать» под отчётом, кнопка «Открыть чат» ДОЛЖНА
   остаться.
4. КОГДА сообщение о переписке из Instagram, кнопка ДОЛЖНА вести на
   Direct с этим человеком.
5. КОГДА сообщение о переписке из MAX, кнопки «Открыть чат» НЕ ДОЛЖНО
   быть.
6. КОГДА собеседник сменил @username, следующая кнопка ДОЛЖНА вести на
   новый.
