# 034. План: две темы, вкладки, «Дела» и карточка

План ремонтного захода: порядок работ и решения по неоднозначностям.
Устройство — `techspec/32-redesign.md` §32.1, §32.2; вид — `design.md`
§1–§3 и артборды `prototype/000-redesign/` (04–10 обоих рядов).

## Порядок (коммит на задачу спеки)

1. `plan.md` (этот файл).
2. База, тема: `supabase/migrations/20261011100000_theme.sql` —
   колонка `owner_settings.theme`, функция `save_theme`, права на колонки;
   тест `supabase/tests/theme.test.ts`.
3. Темы: `miniapp/src/fonts/` (woff2 + OFL), `lib/theme.ts`,
   `lib/telegram.ts` (схема, цвета шапки, кнопка настроек), токены в
   `styles.css`, `components/RollingNumber.tsx`, `components/Backdrop.tsx`,
   ранняя тема в `main.tsx`; тест контраста `lib/contrast.test.ts`.
4. Вкладки: `Tabs.tsx` (четыре), `Empty.tsx` (новый вид и тексты §2),
   `TodayEmpty`/`WeekEmpty` (в `components/Placeholders.tsx`), `App.tsx`
   открывается на «Сегодня».
5. «Дела»: `lib/spheres.ts` (чтение, место, монограмма), `Task` с
   `sphereId` и `duration`, `TaskList`/`TaskGroup`/`TaskRow`,
   `SphereMark.tsx`, переключатель на `Choice`.
6. Карточка и сфера в правке: `supabase/migrations/20261011110000_edit_task_sphere.sql`
   (ключ `sphere_id` в `change_task`), тест в
   `supabase/tests/edit_task_sphere.test.ts`, §3.6 тем же коммитом;
   `TaskCard`, `TaskEdit` (поле «Сфера»), `Actions` (три кнопки),
   `Reminders`, `SourceMessage`.
7. «Оформление»: `ThemeSettings.tsx`, вход по кнопке настроек Telegram.
8. «Без сферы и о себе»: `SpheresTab` (в `components/SpheresTab.tsx`),
   `FactList` как экран из карточки, записи без сферы.
9. Тесты `lib/`, сверка скриншотами с артбордами в обеих темах.
10. Документы и закрытие.

## Решения

1. **Где живёт выбор темы.** Источник правды — `owner_settings.theme`
   (§32.1, интервью 2026-10-11); прежняя строка `design.md` §1 «хранится на
   устройстве, таблиц не заводит» правится по итогам. Копия выбора — в
   `localStorage` под ключом `solomon.theme`: только чтобы первый кадр на
   том же устройстве был в нужной теме, правдой она не считается. Порядок
   при старте: `main.tsx` до первого рендера ставит тему из копии и
   `colorScheme` Telegram; `App` читает `theme` из базы и, если отличается,
   применяет и обновляет копию.
2. **Запись выбора** — функцией `save_theme(theme text) returns
   owner_settings` (`security invoker`, владелец из клейма, явный фильтр,
   только `authenticated`): прямой `update` без фильтра Supabase не
   пропускает, а id владельца у приложения нет. Права на таблицу у
   `authenticated` сужены до `update (theme)`: приложение не может
   переписать пояс. Строки владельца нет (бот ни разу не запускался) —
   `null`, приложение говорит «не получилось сохранить». Незнакомое
   значение — отказ ограничения `owner_settings_theme_check`.
3. **Токены.** Имена — из прототипа (`--bg`, `--surface`, `--surface-2`,
   `--line`, `--ink`…`--ink-3`, `--acc`, `--acc-ink`, `--c-high`/`-w`,
   `--c-guess`/`-w`, `--c-mine`/`-w`, `--c-late`/`-w`, `--c-kind-w`,
   типографика `--t-*`). Прежние `--accent`, `--urgent`, `--important`,
   `--guess`, `--accent-weak`, `--guess-weak` заменяются ими же —
   второго набора нет (`design.md` §1). Не показанные прототипом:
   `--ok` (Банк-люкс `#6CC38A`, Тихая роскошь `#2F7A4D`) и `--acc-w`
   (подложка выбранного в форме). Значения — в `:root[data-skin="bank"]`
   и `:root[data-skin="quiet"]`; атрибут `data-skin` на `<html>` ставит
   `lib/theme.ts`.
4. **Цвет сферы** — `--s-1`…`--s-12` и `--s-none`; место — порядок живой
   сферы по `created_at` (при равенстве — по `id`). Убранная сфера место
   освобождает, следующие сдвигаются. Места 5–12 подобраны здесь (по тем
   же правилам, показать владельцу): Банк-люкс — аквамарин `#5EC8D8`,
   огненный опал `#F0A060`, перидот `#A8D46A`, турмалин `#F096C8`, цитрин
   `#E4CF6A`, лунный камень `#A8B6CC`, танзанит `#8F8FF5`, дымчатый кварц
   `#C8B49A`; Тихая роскошь — морская волна `#3F8288`, слива `#8A587F`,
   пыльная роза `#B8707F`, мох `#7D8740`, лаванда `#7C70AE`, графит
   `#676C75`, бордо `#8E3B4A`, корица `#9A6A42`. Материалы камня 5–12
   нужны только карточке сферы — это 035.
5. **Монограмма сферы** (Банк-люкс): два знака заглавными — два слова:
   первые буквы; заглавная внутри слова («VoiceFin»): первая и она; иначе
   первая и следующая согласная, кроме й, ь, ъ («РЕЙВА» → «РВ», «Семья» →
   «СМ»); одна буква — она одна. Без сферы — «·».
6. **Вкладки в этом этапе.** «Сегодня» и «Неделя» показывают одобренные
   пустые состояния всегда — данных у них до 035 нет (так в спеке).
   «Сферы»: сфер нет — одобренное пустое состояние; сферы есть — шапка
   «N из 12» без карточек (их добавит 035), чтобы не говорить «сфер пока
   нет» владельцу со сферами. В обоих случаях внизу — карточка «Без сферы
   и о себе», если есть дела без сферы или записи о себе (пока не
   прочитаны — тоже есть). Примеры в пустых — нейтральные (`design.md`
   §2): названия сфер владельца в текст не попадают.
7. **«О себе»** — экран `FactList` поверх «Сфер» из карточки «Без сферы и
   о себе», с «назад» Telegram; показывает записи с `sphere_id is null`,
   правка прежняя (§8.4). Записи со сферой покажет карточка сферы (035).
   Память читается при первом открытии «Сфер».
8. **Переключатель «По сроку / По сферам»** — тот же `Choice` с
   модификатором вида (`design.md` §3: второй не заводится). Состояние —
   в `App`, не хранится. По сферам: группы в порядке мест, «Без сферы» —
   последней; внутри — порядок групп срока, дальше как пришло из базы.
   Заголовок группы — название и число дел.
9. **Строка дела**: отметка сферы, суть, «сфера · 📅/🔔 срок» (📅 — срок с
   часом, 🔔 — без часа, у встречи — «14:00–16:00»), повтор «↻», метки
   вторым рядом, «›». Дело без срока — только сфера (как на артборде).
   Слова срока — `formatDue`, теми же словами, что у бота (`texts.format_due`,
   с концом встречи).
10. **Карточка**: шапка-карточка (сфера, суть, время крупно — только у
    срока с часом, ниже день и длительность словами, как у бота: «2 ч»),
    поля стопкой (Разбор, Сфера, Повтор, Вид, Приоритет, Обещание, Люди,
    Напоминания), источник цитатой, внизу «Сделано · Изменить · Удалить»
    (строка «Изменить» под полями уходит в кнопку, как на артборде 05).
    Своя «‹ назад» — только когда кнопки Telegram нет (вне Telegram,
    SDK старше 6.1).
11. **Сфера в форме** — ряд вариантов с переносом («Без сферы» и сферы
    владельца по местам); в `edit_task` уходит `sphere_id` только если
    выбор изменён. Сферы не прочитались — ряд заперт с подсказкой.
12. **`sphere_id` в `change_task`**: строка uuid живой сферы этого
    владельца или `null` (снять). Не строка, не uuid, чужая, убранная или
    несуществующая — исключение `change_task: unknown sphere …`, правка не
    проходит целиком. Расписание и отметку переноса не трогает.
13. **Вход в «Оформление»** — `SettingsButton` Telegram (Bot API 7.0+):
    показывается при старте, касание открывает экран поверх текущего (тот
    остаётся смонтированным — форма правки не теряет введённое). Своего
    входа в разметке нет (как на артборде 06).
14. **Движение.** `RollingNumber` — разряды колонками 0–9, переход
    `transform` 320 мс, разряды слева направо с шагом 40 мс, от прежнего
    значения к новому; при первом показе — от нуля. Полосы — класс `.grow`
    (380 мс). Фон — `Backdrop`, два пятна, только `transform`. При
    `prefers-reduced-motion: reduce` переходов и анимаций нет.
15. **Шрифты** — `@fontsource-variable` 5.3.0 (Inter, Inter Tight, Lora;
    OFL-1.1): только файлы `latin` и `cyrillic` с осью `wght`, Lora ещё
    курсив, в `miniapp/src/fonts/` с текстами лицензий; зависимостью
    пакет не ставится.
16. **Контраст** (приёмка 10) — тест `lib/contrast.test.ts` читает
    `styles.css`, берёт значения обеих тем и проверяет пары «текст — фон»
    не ниже 4,5:1, метки — по подложке поверх карточки.
17. **Прототип** на закрытии уезжает в `prototype/archive/000-redesign/`;
    ссылки этапа 035 на него правятся тем же коммитом.
