# Архив этапов

Закрытые этапы переезжают сюда со своими номерами — папкой целиком,
`git mv specs/<папка> specs/archive/<папка>` в закрывающем коммите.
Номера не переиспользуются.

| № | Этап | Закрыт | Что сделано |
| --- | --- | --- | --- |
| 001 | [Скелет: бот, Mini App, база, ворота](001-skeleton/spec.md) | 2026-09-17 | Бот на aiogram с калиткой владельца, Mini App на Vite, Edge Function `telegram-auth` для входа под правилами доступа, health-запрос к базе, стековые проверки в воротах |
| 002 | [Данные и доступ: задачи в базе, бот пишет, Mini App читает](002-data-access/spec.md) | 2026-09-17 | Таблицы `messages` и `tasks` с правилами доступа по владельцу, приём поручения одной транзакцией через `record_task`, слой операций `services/` в боте, список активных задач в Mini App, чек-лист первого подключения проекта |
| 003 | [Понимание поручений: срок, суть, приоритет — через Claude](003-understanding/spec.md) | 2026-09-20 | Разбор каждого сообщения в Claude одним вызовом со структурированным ответом: вид, суть, срок, приоритет, обещание и люди; сообщение пишется в базу до модели, разбор с задачей и ответом — одной транзакцией; отказ модели не теряет поручение, повтор отвечает сохранённым ответом; живой прогон на десяти русских примерах |
