# Соломон — техническая спецификация

Источник требований: `spec.md` (что строим) и `idea.md` (зачем).
Этот документ отвечает на вопрос **как строим**: решения, схема данных,
контракты, границы слоёв.

Правило приоритета: `spec.md` главнее по продукту, `techspec.md` главнее
по реализации. Противоречие фиксируется и правится в обоих файлах,
а не «решается по ходу».

## Как читать этот документ

Сам документ живёт в папке `techspec/` — по файлу на раздел. Здесь только
указатель. Ссылка вида `techspec.md §4.3` разрешается за один переход
по таблице ниже.

**Читай нужный раздел, а не документ целиком.** Спека этапа в блоке
«Читать» перечисляет свои разделы прямо — начинай с них. Большой раздел
читается окном по строкам: `grep -n '^### N\.'` даёт границы подразделов,
`sed -n 'A,Bp'` читает нужный.

**Разделы заводятся по мере надобности** — когда этап их трогает, не
впрок. Номера разделов не переиспользуются и не переставляются: ссылки
`§N` разбросаны по спекам, коду и комментариям.

## Правила правки

- **Изменение схемы данных** = правка раздела схемы в том же коммите,
  что миграция. Без исключений.
- **Новый инвариант доступа** — в раздел доступа, а не в комментарий
  к коду.
- **Противоречие со `spec.md`** — фиксируется и правится в обоих
  документах.
- Раздел не переезжает в другой файл и не меняет номер.
