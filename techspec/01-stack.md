# §1. Версии стека

Версии зафиксированы точно — без `^` и `~`. Обновление версии — осознанная
правка этого раздела вместе с файлом зависимостей, а не побочный эффект
установки. Замки (`bot/uv.lock`, `miniapp/package-lock.json`,
`supabase/package-lock.json`) лежат в репозитории.

Всё, что ниже, проверено на актуальность по PyPI и npm 17 сентября 2026,
а не взято по памяти.

### 1.3 Edge Functions — Deno

Функции исполняет Deno на стороне Supabase; версию рантайма задаёт
платформа, закреплять её нечем.

Код функций написан на стандартных Web API (`crypto.subtle`, `fetch`,
`Request`/`Response`) и не зависит от того, кто его запускает. Поэтому
типы проверяет `tsc` (TypeScript 6.0.3), а тесты идут на Node 24
(`node --test`, нативный TypeScript): ещё один рантайм разработчику
не нужен. Кусок API Deno, который функции всё-таки используют, описан
в `supabase/types/deno.d.ts`.

### 1.4 Чего в стеке нет

- Общей библиотеки между частями — см. §2.1.
- Менеджера пакетов сверх npm и uv.
- UI-kit: экранов пока нет, выбор делает этап, который их заводит
  (`CLAUDE.md` §«Чего не делаем» запрещает второй UI-kit поверх первого).
- Docker: локально ничего не поднимается, платформа Supabase удалённая.
