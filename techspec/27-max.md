# §27. Бот в MAX

Как Соломон получает переписку из MAX. Личные чаты MAX официально не
читаются (разведка 2026-10-07): бот в MAX — отдельный собеседник, он
видит только написанное ему самому и группы, куда его добавили.
Решения владельца: официальный бот; всё, что нашлось, — в обычный чат с
Соломоном в Telegram; группы, куда владелец добавит бота, тоже читать.
Разбор, хранение, согласие и что видит владелец — общие, §25.

### 27.1 Что делает владелец

Регистрирует бота на business.max.ru (самозанятый, подтверждение через
Госуслуги, модерация до 48 часов), кладёт в `.env` `MAX_BOT_TOKEN` и
свой id в MAX — `OWNER_MAX_ID` (инвариант 2). Нет переменных — источник
выключен. Инструкция — в `README.md`, раздел «MAX».

### 27.2 Связь

HTTP API MAX (`platform-api2.max.ru`), ключ — в заголовке
`Authorization`; обновления — long polling отдельной задачей asyncio в
том же процессе бота, рядом с опросом Telegram. Свой клиент на httpx —
без новой библиотеки. Сертификат `platform-api2.max.ru` выдан
российским удостоверяющим центром (Минцифры), которому сервер не
доверяет: проверка 2026-10-07 — `curl` ошибка 60. Корневой сертификат
лежит в репозитории и добавляется к проверке TLS только для клиента
MAX; на сервере ничего не ставится.

### 27.3 Что бот принимает

- **Личный чат владельца с ботом**: пересланные сообщения — строки
  переписки с исходным отправителем и временем (чат — по отправителю
  пересланного); своё сообщение владельца боту — строка «Вы» в чате
  «MAX: заметки». Голосовые — Deepgram (§9).
- **Группы**, куда владелец добавил бота с правом читать все сообщения:
  сообщение `OWNER_MAX_ID` — `out`, остальные — `in`. В группах только
  договорённости: «ждёт ответа» по группам не считается.
- Сообщения от других людей в личный чат бота — молча пропускаются.

Дальше — общий путь §25 с площадкой `max`. На первую пачку после
тишины бот отвечает в личном чате с владельцем одной строкой «Принял, итог пришлю в
Telegram.»; другого бот в MAX не пишет.

### 27.4 Что не делает

- Не читает личные чаты владельца с другими людьми (юзербот отвергнут).
- Не отвечает в MAX ничего, кроме «Принял…», и не пишет в группы.
- Не ведёт «ждёт ответа» по группам и каналам; каналы не читает.
