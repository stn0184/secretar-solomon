# §29. Значки категорий в сообщениях бота

Владелец (2026-10-09): сообщения бота должны различаться с первого
взгляда — напоминание, задача, встреча. Цвет текста Telegram боту не
даёт (бот шлёт простой текст, без `parse_mode`), поэтому категорию
передаёт значок в начале сообщения. Набор утверждён владельцем.

### 29.1 Набор

| Значок | Сообщение |
| --- | --- |
| ✅ | записал дело (подтверждение записи, список записанного) |
| 💡 | записал идею или желание |
| 🔔 | напоминание о деле без часа (день, часть дня) |
| 📅 | напоминание о деле с часом (`due_precision = time`, §6.1) |
| ☀️ | утренний план (§20) |
| ❓ | вопрос Соломона: о деле без срока (§19), о прошедшем деле (§22), уточняющий (§10), неясная правка |
| ✏️ | правка дела: перенёс, поправил, закрыл, убрал (§12) |
| 💬 | из переписки: отчёт разбора, вопрос о согласии и ответ на него (§25) |
| ⏳ | «Вы не ответили …» (§25.4) |
| 🔍 | поиск: «Ищу», ответ поиска, «не получилось поискать», «не успел» (§24) |
| ⚠️ | не получилось: отказ записи, сбой, «не расслышал» и подобное |

Без значка — ответы в разговоре (§17): бот отвечает как человек; а
также `/help`, `/start`, `/chats` — справка.

### 29.2 Правила

- Значок — первый символ сообщения и пробел после него; одно сообщение —
  один значок. В списке из нескольких дел (§23.4) значок у сообщения, а
  не у строк.
- Значок — оформление, а не текст для узнавания. Всё, по чему бот или
  модель узнают свои слова, работает как раньше: открытый вопрос задачи
  хранится без значка (`UNDATED_QUESTION`, `OVERDUE_QUESTION`, §19.5,
  §22.5), отметка «Сделано» (§6.3) ставится и снимается со значком на
  месте, строки «Ищу: …» и «Куда и на какие числа искать билеты?» в блоке 6
  (§17.3, §24.1) модель понимает и со значком впереди.
- Правка сообщения после кнопки («Сделано», «Убрать», «Вернуть») значок
  сохраняет.
- Тексты значков живут в `texts.py` константами — в одном месте.

### 29.3 Что не делает

- Не красит текст и не меняет формат сообщений (без HTML и Markdown).
- Не ставит значков в ответы разговора и в справку.
- Не меняет приложение.
- Не делает значки настраиваемыми.
