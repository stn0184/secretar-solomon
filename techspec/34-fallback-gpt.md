# §34. Запасная модель GPT-5.5

Что бот делает, когда Claude недоступен надолго. С 2026-10-09 22:25 UTC
посредник agenthello.ai отвечает серверу бота (Франкфурт) на все модели
Claude 503 «No available accounts», а с компьютера владельца тот же ключ
работает — разбор на сервере стоял почти двое суток. Второй ключ
посредника (2026-10-11) даёт с сервера GPT-5.5 через совместимый с
OpenAI Responses API (`https://api.agenthello.ai/v1/responses` — 200),
Claude с ним — 502.

Решение владельца (2026-10-11): **главная модель — Claude, GPT-5.5 —
запасная**: при временном отказе Claude (§33.1) бот сам идёт в GPT-5.5,
когда Claude вернётся — сам возвращается.

### 34.1 Где действует

Все вызовы модели: разбор текста и голоса (§5), снимка (§14.3),
пересланной переписки (§18.2), разбор чата (§25.3), поиск (§24.2).
Если поиск в интернете у GPT через посредника не работает (проверяется
на этапе), поиск остаётся только на Claude и ждёт его — §24.6.

### 34.2 Как переключается

- Временный отказ Claude после повторов SDK → тот же вызов сразу идёт в
  GPT-5.5. Постоянный отказ (§33.1) в GPT не идёт — путь §5.4.
- Три временных отказа Claude подряд — следующие 10 минут вызовы идут
  сразу в GPT (без ожидания Claude), потом снова пробуется Claude.
- Отказали оба — путь §33 («⏳ Принял…», очередь).
- Какая модель ответила — `messages.ai_model` и журнал; владельцу не
  говорится.

### 34.3 Как устроен вызов

Официальный SDK `openai` (новая зависимость, версия — по `uv.lock`),
Responses API, `base_url` и ключ из окружения: `OPENAI_BASE_URL`,
`OPENAI_API_KEY` (инвариант 1; нет переменных — запасного пути нет).
Ответ — структурированный (`text.format` json_schema, strict) по тем же
Pydantic-моделям, что у Claude; строгий режим требует, чтобы все поля
были обязательными и допускали `null` — схема для GPT строится из тех же
моделей автоматически, сами модели не меняются. Тот же системный промпт;
глубина — `reasoning.effort = medium`. Снимок — `input_image` base64.
Поиск — инструмент веб-поиска Responses API, ответ — текст со ссылками
по тем же правилам (§24.2).

### 34.4 Проверка качества

Все примеры разбора (`understanding.jsonl`) прогоняются вживую на GPT-5.5
тем же тестом, что на Claude; расхождения — в отчёт и §34.5, и порог
общего совпадения тот же. Снимки и переписка — свои живые тесты на GPT.

### 34.5 Что не делает

- Не делает GPT главной моделью и не сравнивает модели между собой в
  продукте.
- Не говорит владельцу, какая модель ответила.
- Не переносит поиск на GPT, если его веб-поиск через посредника не
  работает.
- Не меняет промпты под GPT сверх необходимого для совпадения примеров.
